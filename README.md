# Bienvenido a NavTracker para Amplify

NavTracker es un sistema de rastreo de transporte publico que a partir de módulos GPS permite visualizar en 
tiempo real la ubicación exacta de los vehiculos de nuestro interés, permitiendo así planificar nuestros 
viajes de manera más precisa, a continuación se explica el funcionamiento de la página.

---

**Creación de proyecto react vite**

---

```bash
npx create-vite@latest "nombre del proyecto" --template react
npx install axios react-router-dom
```

Iniciar el proyecto

```bash
npm run dev
```
subir el proyecto a git

```bash
git init

git add .

git commit -m "first commit"

git remote add origin https://github.com/NOMBRE_USUARIO/NOMBRE_PROYECTO.git

git push -u origin master
```
Se incia sesión de git en amplify y se dan los permisos para acceder a los repositorios, posteriormente se elige el repositorio específico.

Instalacion en caso de ser necesario clonar el repositorio

```bash
npm install
```
